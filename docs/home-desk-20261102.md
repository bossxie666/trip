# 立体旅行书首页

来源为用户提供的《旅行首页小样-完整源码.zip》。保留小样的书本、开合/翻页顺序、纸雕、右上角唱机和收藏照片横条；现有 SiteHeader、头像、知识库三横线和移动导航保持不变。旅行工作台和相册页不增加翻页动画。

首页仅读取当前成员可见的旅行、相册及相册共同收藏照片。城市坐标沿用现有城市记录；不会在读取首页时调用地理编码。书中无内容时不注入示例旅行或示例风景照。收藏更新调用已有相册接口并沿用权限，失败保留原状态并提示重试。

小样运行代码适配为 `public/assets/travel-desk/desk.js` 与 `scene.js`。Three.js 0.170.0 原文件及 MIT 许可保留在 vendor；样式通过 Shadow DOM 隔离，避免影响其它页面。两首音乐在用户点击后才请求，不自动播放。

WebGL 无法初始化时保留普通功能入口。减少动态效果设置沿用小样处理。空闲停止重复绘制；离开首页取消动画、观察器、监听器、请求并释放纹理和 WebGL 资源。特别修复了音频 load/pause 在卸载后触发文字更新的问题，移除媒体事件后再释放音频，防止路由内容与地址更新不同步。

本次不增加数据库表或新写接口。注册和独立地图以 GitHub `833fb24` 为基线保留。旧地图故障测试改为检查独立地图工具栏与主导航；不恢复已取消的工作台地图章节栏。
