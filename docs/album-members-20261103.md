# 独立相册成员与拖动浏览

- 相册书架、首页收藏横条使用原生横向滚动，触屏可左右滑动，鼠标拖动跟随位移；保留方向按钮，拖动不触发打开相册、图片或替换封面。不改变相册内照片排序。
- 新建/编辑相册提供独立成员选择。创建者固定保留，只有创建者可管理相册资料与成员；选中的成员可以浏览、上传、收藏和维护标签。关联旅行不再隐式决定相册可见人员。
- `0015_album_members.sql` 为旧关联旅行相册一次性复制现有旅行成员及创建者；未关联旅行的旧相册仅保留创建者。后续旅行成员变更不自动修改相册人员。
- 相册列表/详情、首页相册及收藏、城市页入口、媒体直链均遵守相册权限。相册图片改为 `private, no-store`，成员调整写入审计。授权和元数据修改在同一事务内，非法人员不会导致部分保存。
- 正式发布前必须先应用该迁移；本次仅更新 Preview。预览库迁移前已导出备份，文件保存在忽略目录 `work/preview-before-album-members.sql`，不得提交版本库。
- 回退视觉可以单独回退横条代码；不要回退至使用“未关联旅行即全员可见”的旧授权逻辑。新增成员表不删除旧业务数据。

验证包括独立授权/撤销、非成员接口与图片拒绝、旧成员迁移、鼠标拖动防误触、成员勾选保存、手机/桌面完整回归。触屏采用浏览器原生滚动；自动化拖动验证使用鼠标，真实手机手势仍需预览使用确认。

本地发布验证：126 项服务端/迁移测试通过；全站浏览器 49 通过、1 个桌面不适用检查跳过；成员选择和拖动防误触专项补验 4 通过。预览 D1 的 0015 迁移已成功，正式 D1 未应用。
