# 留言可见成员、点赞与回复

- 留言默认全体已登录成员可见；作者可在新建/编辑弹窗选择指定成员，作者始终保留，空选择表示仅自己可见。只提供有效、启用的成员选项。历史留言通过迁移保留原有全员可见行为。
- 留言列表、页面服务端渲染、旧首页聚合读取，以及图片直链均检查当前可见范围。权限筛选在分页数量限制之前执行。留言图片采用 private/no-store；未关联上传仅上传者可见，已删除留言不再授权其图片。
- 可见成员可点赞、取消点赞、查看点赞成员及回复。点赞采用成员与留言复合主键并以 PUT 设置状态，重试不重复计数。回复最多 1000 字，成员只能删除自己的回复，删除需确认。作者删除留言后，关联互动和图片不会再暴露。
- 调整成员与正文在同一个 D1 batch 中提交。写接口校验请求来源、会话、输入和资源权限，统一限流并审计；审计不保存正文。点赞/回复的插入语句再次检查可见权限。
- 编辑与回复继续使用统一纯色居中 EditorDialog，保留未保存提示、焦点恢复、忙碌保护和错误重试。手机操作按钮最小高度 40px，长文本安全换行。

## 发布与恢复

先备份 Preview D1，再应用 `0016_guestbook_social.sql`，最后部署预览 Worker。正式站在独立验收后才能应用迁移和切换版本；正式还需先应用此前的 `0015_album_members.sql`。本次不改正式站。

迁移新增 visibility 列和三张表，不删除旧数据。请勿回退到无可见成员校验的旧留言/媒体接口，这会公开原本限制成员的留言；保留新权限服务，仅回退视觉，或使用迁移前的数据库与对应版本一起恢复。
