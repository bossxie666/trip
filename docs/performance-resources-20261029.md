# 首屏资源与页面样式优化

本轮基于 GitHub `v2.4-r1` 的 `285eb9e`；2026-10-29 再次 fetch 确认远程没有额外提交。

## 改动

- 首页标题、背景和中国地图增加 AVIF 与响应式尺寸，保留 WebP 回退；坐标覆盖层与原有视觉布局不变。
- 不渲染原本被 CSS 隐藏的装饰图片，非首屏影像墙与空留言装饰延迟加载。保留首页“跳进地理书的旅行”、三横线、导航按钮和真实地点关系。
- 首页、旅行书架和工作台样式按路由加载；根样式从约 145 KB 减至 79 KB（构建后未压缩值）。费用和参与状态样式仅随工作台加载。
- 等宽字体不再全站预加载。`/favicon.ico` 直接跳转已有 SVG，不查询私密会话。
- 移除没有代码引用的两份重复旧资源；每次构建清理项目内 dist，避免旧散列资源残留在部署包。

## 验证与限制

- 生产构建、117 项回归、TypeScript、ESLint 通过。完整浏览器流程 21 项通过，1 项桌面跳过手机专用检查。
- Google Chrome 检查旅行书架 320、375、390、430、820、1280px：手机两列、平板三列、桌面四列；当前测试标题没有裁切，无横向溢出。相册标题完整；新增相册弹窗 390px 下为 362×441，x14/y201.5，背景为不透明纯色，内部无背景图。
- 真实构建 HTML 检查：首页不加载工作台样式，书架不加载首页或工作台样式，规划页保留工作台样式。已验证 AVIF 实际被 Chrome 选用。
- 同一台本地电脑、隔离合成数据、Google Chrome 的 Lighthouse 移动模拟两次报告：首页传输量从约 1,212 KB 降至 659 KB，LCP 3,506/3,484ms；书架 4,913/2,488ms，规划 3,483/3,219ms，费用 2,759/4,654ms。CLS 均为 0。
- LCP 尚未稳定达到 2,500ms，性能门禁仍失败，未放宽阈值。这些是实验室数据，不能代替正式站用户的 LCP/INP，也不能据此宣称整站修复完成。
- 本轮不改数据库、媒体上传权限或业务数据；正式发布仍须预览验收与完整发布门禁。后续继续处理资源竞争、重复客户端依赖及其余编辑器。
