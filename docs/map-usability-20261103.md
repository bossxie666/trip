# 旅行地图与少量内容的可用性

- 地区筛选使用旅行真实城市 ID，默认全部；没有选定城市的搜索不再强制偏向上海。地图初始位置优先取当前有效地点，没有地点时显示全国概览。
- 旧 shanghai/hangzhou/tonglu 链接仍兼容，但只在旅行真实城市匹配时生效；桐庐是杭州的兼容子区域，不会把其他城市归到杭州。地区选择保留到 URL，刷新可恢复。
- 相同地点 ID、相同高德 POI ID 或相同有效坐标之间不请求交通路线。规划与地图显示“同一地点，无需交通”，费用估算跳过该段，原事项和地图标记不删除。
- 地图搜索框和筛选器、地图工具栏等待客户端事件绑定后启用，防止刷新后第一次输入或切换丢失。
- 相册书架只有实际溢出时显示左右按钮，到起止边界时禁用对应方向；边界考虑书架留白和吸附位置。收藏照片同样按实际溢出决定是否显示翻组按钮，保留已有紧凑空状态。
- 头像资料增加知识库、我的形象快捷入口，保留主导航和侧栏；密码输入未保存时仍需确认才能离开。书名增加悬停/聚焦反馈，不新增封面替换文字。

不变更数据库结构、权限、媒体存储或正式数据。浏览器测试只使用独立本地合成数据；地图筛选请求测试主动模拟 SDK 不可用，不代表真实高德服务验收。城市和同地点判断有纯函数回归；手机/桌面验证筛选、搜索作用域、刷新、重复地点、相册拖动、少量照片以及资料未保存提醒。
