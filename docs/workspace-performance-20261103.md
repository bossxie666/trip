# 工作台首屏样式加载

正式版本 0893b64 的云端报告中，规划和费用页的 LCP 元素都是旅行标题，主要耗时为显示等待。HTML 已包含内联样式，客户端绑定时仍会重新下载相同的四份样式文件，形成脚本之后再次加载样式的请求链。

本次只关闭 vinext 1.0.0-beta.2 的 experimental.inlineCss。样式内容、优先级与页面交互保持原样，让浏览器从初始 HTML 直接发现带哈希的样式文件，避免内联后再外链的重复传输。保留原有按页样式拆分、脚本预加载凭据修正及按钮就绪保护。

不变更数据库、媒体、权限、地图或导航逻辑，不放宽任何性能门禁。本地性能验证使用 `.wrangler/performance-v2` 中与 CI 相同的独立合成数据库，避免历史失败测试留下的数据影响排序和页面规模。该目录和报告不提交 Git。
