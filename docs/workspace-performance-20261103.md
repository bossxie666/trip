# 工作台首屏减负

正式版本 0893b64 的云端 Lighthouse 报告中，规划、费用页的 LCP 分别约为 2.76、2.55 秒。旅行标题是 LCP 元素，显示等待占主要部分。

## 实施

- 清理约 11 KB 的旧攻略卡片、资料库和旧费用弹窗样式。只移除全部应用和组件源码都未引用的类名；混合选择器保留有效部分。用浏览器在 320、390、430、1280px 的规划和费用视图验证移除规则不匹配当前 DOM。
- PlanningPanels 只有静态布局，改为服务端组件。成员和城市简要参数在同次渲染中复用。
- 住宿添加、住宿/交通编辑、费用订单编辑、记账及消费编辑按点击加载；初始页面不初始化未打开表单的状态和分摊数组。
- 表单下载时立即显示既有居中纯色弹窗，支持取消、失败提示及重试；取消后晚到的下载不会重新打开弹窗。
- 知识库添加、当天成员与留言操作沿用客户端就绪保护，避免首次点击早于事件绑定。
- 将公共导航运行时代码集中到一个缓存文件，减少逐个入口组合生成的碎片请求。只调整浏览器代码分包，不更改导航结构或路由。

## 测量与取舍

曾尝试关闭 vinext 的 inlineCss，消除了客户端重复请求相同 CSS 的传输，但云端 LCP 没有改善，规划页甚至接近 3 秒，因此最终保留正式站的内联样式设置。不能只依据资源体积判断收益。

不变更数据库、媒体、权限、地图、导航或业务接口，不放宽性能门禁。原有保存验证、未保存提示、失败重试和删除确认继续由原编辑器负责。

本地浏览器及 Lighthouse 使用与 CI 相同的独立合成数据库 `.wrangler/performance-v3`，与正式/预览数据隔离。工具状态、截图和报告不提交 Git。已有 API 和渲染测试继续验证相同业务要求，源文件检查随表单拆分调整到对应文件。
