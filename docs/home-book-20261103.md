# 首页开书、交互精简与背景统一

- 首次开书原本点击后才串行加载 scene.js 和约 1.37 MB 的完整 Three.js r170 文件。本次用同一源文件只导出书本用到的 21 个 API，裁剪压缩为约 566 KB；gzip 从约 267 KB 降至 127 KB。生成命令为 node scripts/build-book-engine.mjs，原始带许可证文件保留。
- 鼠标意图、键盘聚焦或页面空闲时准备代码，不提前初始化 WebGL。节省流量或 2G 连接不自动准备。代码下载超过 15 秒提供重试；晚到的下载不会自行打开。硬加载失败提供重新加载。封面使用既有 card 尺寸；无封面的占位纹理复用。
- 开合动画从 1700ms 缩为 900ms、翻页从 1800ms 缩为 950ms；减少重复初始重建，保留原有材质、模型、阴影与减少动态效果支持。动画中控件正确禁用，结束后立即可操作。
- 移除书下章节按钮行、单独合上按钮及底部重复导航。点击纸面前翻，末页再点空白纸面合书，真实旅行/相册卡片继续打开内容。保留左右翻页、键盘、滑动和页面恢复；书页条目仅在键盘聚焦时提供功能入口。
- 全站页面外层统一为首页米色径向背景，停用旧壁纸变量和装饰加载组件；页面主体透明，卡片与弹窗保留自身纯色/书本样式。首页标语和主导航不改。全局错误页使用同样背景。

验证包括手机/桌面的纸面点击、键盘链接、章节刷新恢复、慢下载超时与重试、七个路由背景和横向溢出。UI 请求模拟与真实 3D 渲染均在独立本地合成数据中运行，不修改正式内容、数据库或权限。文件缩减不等于所有网络环境下打开时间按同比例缩短。
