# 正式切换前的安全与首屏修补

原候选的 GitHub CodeQL 检查标记了 Three.js 0.170.0 的弱随机 UUID。保留 MIT 许可，并将该函数的随机源改为 Web Crypto；安全随机源不可用时直接失败，不退回 Math.random。新增回归验证 UUID 格式、唯一性和熵源失效行为。

首页原本在首次加载时创建完整 WebGL 场景与多张画布纹理，造成约 1.4–2 秒的模拟移动端阻塞。现先显示从同一渲染器导出的透明书本封面，点击开书时才加载 Three.js。恢复已打开的章节仍会自动初始化，不恢复音乐播放。异步初始化保留中止、失败重试和离页清理。

首屏外层预留完整高度，封面在服务端预渲染并预加载，避免加载占位被立体书替换时推移页面。页面 CSS 使用当前 vinext 支持的内联模式，路由样式测试同时检查内联和外链形式。合并公共导航控件与图标的小模块，业务编辑器继续独立加载。

书架用展示尺寸 WebP 占位封面，用户封面继续请求受权限保护的 card 版本，预加载与实际图片使用同一 URL。中文书法和标题字体不变；正文和等宽数字采用系统字体回退，取消两次远程字体下载。临时 QA 脚本和备份目录不参与应用 ESLint，也不提交 Git。

不放宽 Lighthouse、权限或安全检查。正式切换前必须检查最新 GitHub 结果，先备份正式 D1，再应用 0015、0016，最后发布对应 Worker。旧的无相册/留言可见成员校验的代码不能单独回滚，否则可能暴露新建的受限内容。
